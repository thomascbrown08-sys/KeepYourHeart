If everything says MISSING on GitHub Pages but works locally: the folder almost certainly did not survive the commit. Git does not track empty directories, so assets/img/ vanishes unless it has a file in it. Check that assets/img/ actually exists in the repo file list on github.com.

Fastest single test: paste one image URL straight into the address bar — https://<you>.github.io/<repo>/assets/img/ch01.jpg. If that 404s, it is a file-location problem. If it loads but the page is still blank, it is a CSS or cache problem and a hard refresh is the next step.

Watch the capitals. GitHub Pages is case-sensitive. Ch01.JPG will work on your Mac or Windows machine and fail on the live site.
